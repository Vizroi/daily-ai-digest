    在虚幻引擎5中制作实时沙漠神庙场景Creating Real-Time Desert Temple Environment In Unreal Engine 5

    3D环境美术师Marc Castells介绍其虚幻引擎5沙漠神庙场景的制作过程，包括基于Edward Barons概念图扩展构图、在Maya中建模并复用建筑资产、用SpeedTree制作植被、ZBrush雕刻岩石，以及用RGB遮罩混合材质、Runtime Virtual Texturing和基于遮蔽的材质函数处理资产与地形的衔接。

    策划视角可关注作者如何在概念图未覆盖的视角区域延续原有视觉语言，以及RGB遮罩与Runtime Virtual Texturing两种衔接方案在实际场景中的取舍依据。

    背景与变化

    作者以复用主神庙资产和Lattice变形控制制作量，用RGB遮罩在单张纹理中存储三通道遮罩以控制材质过渡，并说明构图扩展、光照与阴影分层服务于突出主神庙这一焦点。
