精选 01分析#

反向教程：用禁止式提示引导玩家行为Reverse-Tutorials and How to Use Them

作者介绍“反向教程”做法：用权威口吻禁止玩家做某事，反而激发其尝试动机。文中举例：开场警告玩家不要读书，读书人数增至三倍；告示称钓鱼违法后钓鱼行为增加；警告不要和石头说话，玩家随即去按交互键。

设计选择
作者主张把教程提示包装成专横权威的禁令，利用逆反心理；并指出善意NPC的劝阻在《星际拓荒》中效果相反，最终版改为明确禁令。
策划视角
可研究：这类禁令式引导在哪些玩家群体或叙事语境下会失效，甚至让玩家误以为该内容真的不该做？

精选 02分析#

《修仙:但天道是AI》开发日志:无状态逻辑与纯数据服务器架构

独立开发者介绍《修仙:但天道是AI》服务器架构:把世界数据与计算逻辑拆开,数据只存不主动运行,逻辑无状态、每次调用读取数据并返回新数据,以支持重启、换机与多机计算,代价是每次请求需携带数据。

设计选择
作者以进程内保存世界状态会导致重启丢局、机器满载无法迁移为由,选择无状态逻辑加纯数据,并说明通过数据瘦身控制传输成本。
策划视角
可追问:无状态逻辑下,战斗或事件裁决的随机性与一致性如何保证?数据瘦身在哪些字段上取舍?
