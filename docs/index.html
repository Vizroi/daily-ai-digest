  9. 09开发动态11.10#

    3D角色艺术家谈月光奇幻角色Galatea的制作流程Making an Ethereal, Moonlight-Inspired Fantasy Character in 3D

    3D角色艺术家Alex Borkovskiy介绍个人电影化项目Galatea的制作：从Photoshop完整2D概念出发，在ZBrush雕刻、Marvelous Designer做服装块面、TopoGun与Blender拓扑、Substance 3D Painter贴图，最后在Maya中用Arnold布光渲染。

    策划视角可研究：在无多边形预算限制的个人项目中，作者如何判断哪些细节交给贴图与烘焙、哪些必须保留几何，这一取舍在游戏资产管线中是否成立？

    背景与变化

    作者先细化2D概念作为项目地图，用圆形母题统一造型；头发以发卡在ZBrush中围绕头部拼装；贴图靠高度与粗糙度区分材质，灯光用HDRI加主光与多盏辅助光控制形体与宝石、耳朵透光。
