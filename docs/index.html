精选 01分析#

《足球经理2027》主创谈引擎迁移、UI重构与战术系统

机核在试玩会圆桌群访中与Sports Interactive主创交流，内容涉及《FM26》转向Unity时低估UI重构难度、《FM27》以效率、可预测性、熟悉感重构UI、恢复重新加载皮肤按钮、推出战术执行力系统、免费抢先体验发行策略及AI使用边界。

设计选择
作者以问答形式记录主创对开发取舍的说明：导航与信息分离、弹窗回归全屏、以战术复杂度减少神阵通吃、AI仅用于辅助且不裁撤员工。
策划视角
可对照《FM26》社区反馈，考察“效率、可预测性、熟悉感”三原则在具体界面改动中如何落实，以及战术复杂度是否真能改变跨级别通吃的策略。

精选 02分析#

《卷尺人》开发日志：从Game Jam到完整解谜游戏的机制迭代

开发者RoyRosta回顾《卷尺人》从GMTK 2024 Game Jam两天原型扩展为约4小时流程Steam游戏的过程，围绕测量玩法，讲述卷尺上限、障碍保持测量、跨屏幕谜题等机制的多次调整，以及关卡编辑器、图示教学和美术风格的选择。

设计选择
作者以Leap Year、Öoo、Elechead等作品为参照，将无限扔卷尺改为拾取提升上限，把障碍改为需持续测量才消失，并借存档点回收卷尺支持跨屏谜题；机制不够直觉时用图示补足。
策划视角
可研究作者如何判断哪些机制靠关卡自解释、哪些需图示辅助，以及把玩家非预期解转为预期解的取舍标准。
