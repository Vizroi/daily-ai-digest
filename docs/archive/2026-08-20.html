Geolocating a random island using geometry and CUDA programming

分析源 +8HN 409 +12HN 头条 +8
发生了什么
作者用CUDA GPU编程和OpenStreetMap全球海岸线数据（882MB，141,131个热带多边形），通过几何指纹匹配定位随机岛屿。流程：点击GUI记录3个岛屿像素坐标→计算角度和距离比→经纬度过滤、密度过滤（5km内≤10邻居）、聚类（20km内≥3点）、生成8070万三角形→每三角形一个CUDA线程并行匹配，容差±20%。
为什么重要

对你而言

A 3D fruit fly on macOS desktop powered by the real FlyWire connectome

分析源 +8HN 372 +11.8HN 头条 +8
发生了什么
macOS桌面3D果蝇，由真实FlyWire连接组驱动：23,210个神经元胞体位置（v783共139,255个），668神经元回路含约19,000个真实突触，以1kHz LIF模拟运行。逃逸非脚本，光标逼近触发LC4/LPLC2，巨纤维细胞经约1,200个前馈抑制突触在约4ms内放电。代码MIT，数据CC BY-NC 4.0。
为什么重要

对你而言
